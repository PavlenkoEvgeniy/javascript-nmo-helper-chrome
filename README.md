# 📚 НМО Помощник

Небольшое Chrome-расширение для тех, кто проходит тесты на портале НМО. Оно
собирает текст текущего вопроса и варианты ответов в один аккуратный промпт —
его остаётся только вставить в чат с ИИ.

Расширение ничего не отправляет на серверы: данные читаются со страницы, а
промпт попадает в буфер обмена.

## ✨ Что умеет

- 🔍 **Находит** на странице тему, текст вопроса, тип вопроса и все варианты ответов.
- 👁 **Показывает** извлечённые данные в popup — можно сразу проверить, что всё
  распознано правильно.
- 🤖 **Собирает** из них готовый промпт и копирует его в буфер обмена одной кнопкой.

## ⚙️ Установка

### 📦 Обычная (без сборки)

1. Скачайте свежий `nmo-helper-<версия>.zip` со страницы
   [Releases](https://github.com/PavlenkoEvgeniy/javascript-nmo-helper-chrome/releases).
2. Распакуйте архив в любую постоянную папку.
3. Откройте `chrome://extensions/` и включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите папку, в которой
   лежит `manifest.json`.

Архив из CI можно взять и без релиза: Actions → нужный запуск → Artifacts →
`nmo-helper-extension`.

### 🛠 Из исходников

1. `npm ci`
2. `npm run build`
3. Загрузите в Chrome папку `dist/` (так же, как в шаге 4 выше).

## 🚀 Как пользоваться

1. Откройте страницу с вопросом теста НМО.
2. Нажмите на иконку расширения в панели Chrome.
3. Нажмите **Парсить страницу**.
4. Проверьте тему, вопрос и варианты ответов в popup.
5. Нажмите **Копировать промпт** и вставьте его в чат DeepSeek, ChatGPT, Claude
   или другого ассистента.

💡 **Совет:** если приложить к чату файл с клиническими рекомендациями, шанс на
правильный ответ заметно выше.

## 🏗 Как это устроено

- Popup (`src/popup/index.ts`) просит данные у content script через
  `chrome.tabs.sendMessage`. Если скрипт на странице ещё не запущен, popup
  подключает его через `chrome.scripting.executeScript` и повторяет запрос.
- Content script (`src/content/index.ts`) находит нужные элементы по CSS-классам
  и передаёт их в чистую логику из `src/lib/`.
- `src/lib/extract.ts` извлекает данные, `src/lib/prompt.ts` собирает промпт,
  `src/popup/render.ts` рисует результат в окне расширения.

## 💻 Разработка

```bash
npm ci              # зависимости
npm run build       # сборка dist/
npm run test        # Vitest + jsdom
npm run lint        # ESLint
npm run typecheck   # TypeScript
npm run package     # nmo-helper-<версия>.zip из dist/
```

После `npm run build` загружайте распакованное расширение из `dist/` — именно
эта папка попадает в релизный архив.

## 📦 Релизы

1. Поднимите версию в `package.json` и `src/manifest.json` — они должны совпадать.
2. Поставьте тег `v<версия>` и запушьте его:

   ```bash
   git tag v1.1.3
   git push origin v1.1.3
   ```

3. GitHub Actions прогонит тесты, соберёт `nmo-helper-<версия>.zip` и создаст
   GitHub Release с этим архивом.

Обычный CI тоже собирает архив и кладёт его в Artifacts каждого запуска, так что
сборку можно проверить, не создавая релиз.

## 📋 Требования

- Chrome 88+ (Manifest V3).
- Разрешения: `activeTab` и `scripting` — нужны, чтобы прочитать текущую
  страницу только после нажатия кнопки.

## ⚠️ Ограничения

Расширение ищет элементы по CSS-классам портала НМО. Если портал обновит
разметку, парсинг может перестать находить поля — тогда достаточно поправить
селекторы в `src/lib/extract.ts`. Если заметили такую поломку, лучше открыть
issue с примером страницы.
